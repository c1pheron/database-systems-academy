Oddiy Java Rejimi

Ushbu rejimda siz hech qanday topshiriq cheklovisiz istalgan Java dasturini erkin yozishingiz, klasslar yaratishingiz hamda haqiqiy OpenJDK 21 kompilyatorida ishga tushirishingiz mumkin.

Foydali Tavsiyalar:

  • Dasturni ishga tushirish uchun class Main va public static void main(String[] args) metodi bo'lishi lozim.
  • Standart paketlar qo'llab-quvvatlanadi: java.util.*, java.io.*, java.math.* va b.
  • Yozgan kodingiz avtomatik saqlanib qoladi va boshqa sahifalarga o'tganda ham o'chib ketmaydi.
  • Natijani ko'rish uchun yuqoridagi "Ishga tushirish (OpenJDK 21)" tugmasini bosing!
