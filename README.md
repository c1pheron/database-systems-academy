## 🏛 3 ta Asosiy Akademik Modul va Professor-Agentlar Tizimi

Platforma talabalarning zerikib qolishini oldini olish, passiv o'qishdan voz kechish va bevosita **Coursework (CW) hamda Viva** imtihonlariga tayyorlash uchun 3 ta ixtisoslashgan modulni qamrab oladi:

### 1. 🏛 Database Systems (`5BUIS009C`) — Professor Atlas
* **Asosiy Maqsad:** **CW1 (70%)** Amaliy Loyiha va majburiy jonli **Oral VIVA** ga tayyorgarlik.
* **10 Qavatli To'liq DDL/DML Arxitekturasi (150 Challenges):**
  - **1-Qavat:** Session Setup, `SET search_path`, `CREATE SCHEMA`, va asosiy ma'lumot turlari (`integer`, `varchar`, `numeric`, `boolean`, `date`, `timestamp`, `text`).
  - **2-Qavat:** Birlamchi Kalitlar, `GENERATED ALWAYS AS IDENTITY`, `START WITH / INCREMENT BY`, Composite PKs.
  - **3-Qavat:** Biznes Cheklovlari: `NOT NULL`, `UNIQUE`, `CHECK (budget >= 0)`, `CHECK (salary > 0 AND salary <= 5000)`, `CHECK (email LIKE '%@%')`, va `DEFAULT`.
  - **4-Qavat:** **DML: INSERT INTO** (Barcha ustunlar, NULL ustunlar, Batch Multi-row, `OVERRIDING SYSTEM VALUE`, `RETURNING id`, `RETURNING *`).
  - **5-Qavat:** **DML: UPDATE** (Bitta/ko'p ustun, `salary * 1.10`, `SET salary = DEFAULT`, shartli `WHERE`, `dob` kiritish, `RETURNING id, budget`).
  - **6-Qavat:** **Tashqi Kalitlar (FOREIGN KEY)** (Inline/Table-level `REFERENCES`, self-referencing `manager_id`, `sales_team`, `project_assignment`).
  - **7-Qavat:** **DML: DELETE & Referential Actions** (`DELETE FROM ... WHERE`, `TRUNCATE TABLE`, `TRUNCATE RESTART IDENTITY`, `ON DELETE CASCADE`, `ON DELETE SET NULL`, `ON DELETE RESTRICT`, `ON UPDATE CASCADE`).
  - **8-Qavat:** **ALTER TABLE — Struktura O'zgarishlari** (`ADD COLUMN`, `DROP COLUMN`, `RENAME COLUMN`, `ALTER COLUMN TYPE`, `ALTER COLUMN SET NOT NULL`, `DROP NOT NULL`, `SET DEFAULT`).
  - **9-Qavat:** **ALTER TABLE — Cheklovlar Boshqaruvi** (`ADD/DROP CONSTRAINT` PK, FK, UQ, CHECK va kaskadli o'chirish).
  - **10-Qavat:** **Relyatsion Algebra & Viva Capstone** (Tanlash $\sigma$, Proyeksiya $\pi$, Dekart ko'paytmasi $\times$, Tabiiy bog'lanish $\bowtie$, Equi-Join, To'plamlar $\cup, \cap, -$, va 6 ta bog'langan jadval hamda siklik FK yechimi).

### 2. ☕ Object-Oriented Programming (`5COSC018C`) — Professor Ada
* **Asosiy Maqsad:** **Assessment 2 (50%)** Guruh ishi — Java Console Order Application + GoF Design Patterns.
* **Qamrovi:** Clean Code, SOLID tamoyillari, GoF Design Patterns (Creational: Factory/Builder/Singleton; Structural: Adapter/Decorator/Composite; Behavioural: Strategy/Observer/Command), UML Class/Sequence diagrammalar va 150 ta qadamma-qadam masalalar.

### 3. 🐧 Operating Systems (`5COSC041C`) — Professor Turing
* **Asosiy Maqsad:** **CW1 (40%)** Individual Case Study (2,500 so'z) + original Bash avtomatlashtirish skripti.
* **Qamrovi:** Linux Terminal & Bash Scripting, Jarayonlar va `fork()`, Xotira boshqaruvi (Paging, Virtual Memory), CPU Scheduling algoritmlari (Round Robin, SJF), Cron avtomatlashtirish va Docker konteynerlashtirish.

## 🚀 Texnologik Stack va Xususiyatlar

* **Telegram Mini App (TMA):** Telegram ichida to'liq ekranli WebApp sifatida ishlaydi ([@seventyoneplus_bot](https://t.me/seventyoneplus_bot) orqali).
* **100% Client-Side Engine:** HTML5, CSS3, Canvas 2D va Vanilla JavaScript. Hech qanday og'ir server yoki kutubxonalarsiz bir zumda yuklanadi.
* **Pinpoint Syntax & Relational Diagnostics:** `database_sql_diagnostics.js` orqali talaba yozgan SQL kodining har bir qatori, tinish belgilari (`;`, `()`, `''`), kalit so'zlari va semantikasi bo'yicha darhol o'zbek tilida aniq tavsiyalar beriladi.
* **Real-time Live Leaderboard & User Sync:** 3 ta modul bo'yicha umumiy reyting, XP hisobi, podium (Top 3) va `@seventyoneplus_bot` orqali natijalarni avtomatik sinxronlash.
