# Database Systems Interactive Academy 🚀

An interactive 2D educational simulator and learning portal for **Database Systems**, covering conceptual design, relational theory, query engineering, and NoSQL architecture.

Designed for desktop browsers and seamless integration as a **Telegram Mini App (TMA)**.

---

## 📚 Curriculum Structure

| Module | Core Topics | Status |
| :--- | :--- | :--- |
| **Week 1** | Conceptual Design, ER Modeling, Multiplicities, Weak Entities, Ternary Relations, Connection Traps (Fan & Chasm) | ✅ Complete |
| **Week 2** | Relational Model, ER-to-Relational Mapping (1:1, 1:N, M:N), Foreign Keys, Integrity Constraints | ✅ Complete |
| **Week 3** | Enhanced ER (EER) Modeling, Specialization / Generalization, Disjoint / Overlapping, Total / Partial Constraints | ✅ Complete |
| **Week 4** | Relational Algebra Operations ($\sigma, \pi, \bowtie, \cup, -$), Functional Dependencies, Normalization (1NF–BCNF) | ✅ Complete |
| **Week 5** | SQL Engineering, DDL & DML, Multi-table Joins, Aggregate Functions, Correlated Subqueries, Database Triggers | ✅ Complete |
| **Week 6** | Transaction Management (ACID, Concurrency, 2PL, Deadlocks), NoSQL Document Modeling (MongoDB CRUD & Pipelines) | ✅ Complete |

---

## 🎮 Features
- **100% Client-Side:** Pure HTML5, CSS3, Canvas 2D, and Vanilla JavaScript. Runs 24/7 without back-end servers.
- **Telegram Mini App Ready:** Integrated with Telegram WebApp SDK (`telegram-web-app.js`) for full-screen mobile and desktop play.
- **2D Interactive Canvas:** Visual database modeling atelier, schema diagrams, and real-time validation.
- **Command & Architecture Anatomy Cards:** 5-point pedagogical breakdown for every concept and query.
- **Unified Progress Tracking:** Offline `localStorage` synchronization across all 6 modules.
